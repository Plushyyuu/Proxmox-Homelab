Why Proxmox?
-----------

I chose Proxmox VE rather than a single operating system for my homelab because of its flexibility. Being able to use isolated virtual machines and containers allows me to run multiple operating systems and prevent any applications from interfering from each other. I used Proxmox because I also did not want to go through the troubleshooting process of fixing errors during a initial installation of one traditional operating system. Proxmox fit my needs to begin learning and expanding my knowledge in server hosting, maintenance, and configurations to aid in the process of showcasing my skills to an employer.
